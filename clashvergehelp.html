Windows 使用教程

注意：Windows 请下载 Clash Verge_2.5.1.exe 版本。
  1. 下载并安装
    在首页下载安装包，双击安装。安装完成后桌面会出现 Clash Verge 图标，双击打开。
  2. 设置中文语言
    打开软件 → 点击左侧 Settings → 找到 Language → 选择 Chinese → 界面变成中文。
  3. 导入订阅链接
    1. 复制你购买的机场订阅链接。
    💡 提示：不想付费可体验免费节点，请访问 此网页 (jd.222260.xyz) 获取。
    (注意：请打开网页复制里面的"订阅链接"，不要直接把网页地址填进去)
    2. 点击软件左侧 订阅 → 顶部输入框粘贴链接 → 点击 导入。
    3. 导入成功后，点击一下刚才导入的配置卡片，使其变成选中状态（颜色变亮）。
  4. 开启代理
    点击左侧 代理 → 点击右上角 WiFi 图标 → 选择一个节点。
    最后点击左侧 设置 → 打开 系统代理 开关。现在你可以访问 Google 了！

macOS 使用教程

注意：M1/M2/M3/M4 芯片请下载 aarch64 版本，Intel 芯片下载 x64 版本（当前 v2.5.1）。
  1. 安装与授权
    下载 dmg 文件打开，将 Clash Verge 拖入应用程序文件夹。首次打开如果提示"无法验证开发者"，请去 系统设置 → 隐私与安全性 中点击"仍要打开"。
  2. 配置订阅
    操作步骤与 Windows 完全一致：
    设置 → 语言改中文 → 订阅 → 粘贴链接导入 → 选中配置文件。
  3. 开启增强模式 (推荐)
    Mac 系统推荐开启 "Tun 模式" 或 "增强模式" 以获得更稳定的体验。设置中找到 Tun 模式 并开启（可能需要输入开机密码）。然后开启 系统代理 即可。

安卓手机教程 (Clash Meta)

手机端没有 Clash Verge，请下载本站提供的 Clash Meta.apk。
  1. 安装 APP
    下载 apk 文件安装。如果浏览器提示风险，请选择"继续安装"或"授权安装"。
  2. 一键导入或手动导入
    方法一 (推荐)： 在机场官网点击"一键导入 Clash"。
    方法二： 复制订阅链接 → 打开 APP → 点击 配置 → 右上角 + 号 → 从 URL 导入 → 粘贴链接并保存。

    ⚠️ 重要：导入成功后，一定要在配置列表中【点击选中】该订阅（前面会出现绿色选中条），否则无法连接！
  3. 启动连接
    回到主界面 → 点击 已停止 按钮（变成运行中） → 首次连接弹出"网络连接请求"，点击 确定/允许。
    点击 代理 选项卡可以切换不同节点。
