Hiddify 全平台保姆级教程
更新于 2025-12-22  |  魔法云盘
Hiddify 是目前最适合新手的软件，界面简洁，全平台（电脑/手机）操作逻辑几乎完全一样。
Windows & macOS 教程
  1. 下载并安装
    在首页下载对应系统的 Hiddify 安装包（Windows 下载 .exe，Mac 下载 .dmg），双击安装并打开。
  2. 设置语言（可选）
    软件通常会跟随系统语言。如果是英文，点击左侧 Settings -> App Language -> 选择 简体中文。
  3. 一键导入配置
    1. 复制你的订阅链接。
    💡 提示：不想付费可体验免费节点，请访问 此网页 (jd.222260.xyz) 获取。
    (注意：请打开网页复制里面的“订阅链接”，不要直接把网页地址填进去)
    2. 打开 Hiddify，点击中间上方大大的 + 号 (新配置)。
    3. 选择 从剪贴板添加。软件会自动识别并导入。
  4. 一键连接
    点击屏幕中间巨大的 连接按钮（圆形图标）。当它变绿并显示“已连接”时，即可开始上网。
    默认是“自动选择”最快节点，你也可以点击下方的 代理 按钮手动选择国家/节点。
安卓手机教程
  1. 安装 APP
    下载本站提供的 Hiddify.apk 并安装。
  2. 导入订阅
    1. 复制订阅链接（或免费节点链接）。
    💡 提示：免费节点请访问 jd.222260.xyz 获取 (复制网页内的订阅链接)。
    2. 打开 APP，点击右上角的 + 号。
    3. 点击 从剪贴板导入。
  3. 点击连接
    点击中间的大圆钮进行连接。首次连接时，安卓系统会弹出“网络连接请求”，请点击 确定。
    看到顶部出现 VPN 图标即代表连接成功。
iOS / iPhone 教程
非常重要：请必须使用 非中国大陆地区 (如美区/港区) 的 Apple ID 下载！
中国区 AppStore 搜索到的 Hiddify 均为盗版/伪劣软件，无法使用。
  1. 下载软件
    登录外区 Apple ID 后，在 AppStore 搜索 Hiddify
  2. 导入订阅
    1. 复制订阅链接（或免费节点链接）。
    💡 提示：免费节点请访问 jd.222260.xyz 获取 (复制网页内的订阅链接)。
    2. 打开 Hiddify APP，点击右上角的 + 号。
    3. 选择 从剪贴板导入。
  3. 允许权限并连接
    点击中间的大圆钮连接。系统会弹出“Hiddify Would Like to Add VPN Configurations”，点击 Allow (允许) 并验证密码/面容。
    按钮变绿即连接成功。
