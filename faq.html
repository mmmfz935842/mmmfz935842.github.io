下载问题

下载速度很慢怎么办？

服务器位于海外，下载速度受网络波动影响。建议：

  1. 优先使用线路1（主线推荐）
  2. 如果线路1慢，请依次尝试线路2、3
  3. 避开网络高峰期（如晚间）下载
  4. 使用下载工具（如IDM）可提高稳定性
下载链接打不开怎么办？

部分线路可能临时失效，请按以下步骤尝试：

  1. 点击下载按钮，弹出线路选择窗口
  2. 依次尝试每条线路
  3. 如果所有线路都无法访问，可能是网络问题，请稍后再试
下载的文件损坏怎么办？

文件损坏通常是下载不完整导致的：

  • 重新下载一次
  • 更换一条下载线路
  • 关闭浏览器的下载加速功能
  • 使用下载工具（如IDM）确保完整性

安装问题

Windows Defender 报毒怎么办？

代理客户端因涉及网络操作，可能被杀毒软件误报。

本站提供的软件均来自官方GitHub仓库，可放心使用。

解决方法：

  1. 打开 Windows 安全中心
  2. 点击"病毒和威胁防护"
  3. 点击"管理设置"
  4. 暂时关闭"实时保护"
  5. 安装完成后重新开启
Mac 提示"无法验证开发者"怎么办？

这是 macOS 的安全机制，解决方法：

  1. 打开系统设置 → 隐私与安全性
  2. 找到被阻止的应用信息
  3. 点击"仍要打开"
  4. 输入密码确认
安卓安装提示"风险应用"怎么办？

安卓系统对非应用商店的 APK 会有安全提示：

  1. 点击"继续安装"或"授权安装"
  2. 如果提示需要开启"未知来源"，请在设置中允许
  3. 安装完成后可恢复原设置
应该下载哪个版本？

根据你的系统选择：

  • Windows：下载 .exe 安装包
  • Mac (M1/M2/M3/M4芯片)：下载 aarch64 或 arm64 版本
  • Mac (Intel芯片)：下载 x64 或 amd64 版本
  • 安卓：下载 .apk 文件

提示：不确定 Mac 芯片类型？点击左上角苹果图标 → 关于本机 → 查看"芯片"信息。

连接问题

导入订阅后无法连接怎么办？

请按以下步骤检查：

  1. 确认已选中配置文件 - 导入后必须点击选中该订阅
  2. 选择节点 - 在代理页面选择一个节点
  3. 开启系统代理 - 在设置中打开"系统代理"开关
  4. 检查订阅是否过期 - 联系机场客服确认
连接成功但无法访问网站？

可能原因及解决方法：

  • DNS 问题：尝试切换节点
  • 节点失效：选择其他延迟低的节点
  • 代理模式：尝试开启 Tun 模式
  • 浏览器缓存：清除浏览器缓存后重试
如何测试节点延迟？

各客户端测试方法：

  • Clash Verge：代理页面 → 右上角刷新图标
  • FlClash：代理页面 → 右上角测试按钮
  • Hiddify：自动测试，显示在节点名称旁

提示：延迟越低越好，建议选择 100ms 以内的节点。

订阅链接在哪里获取？

订阅链接获取方式：

  1. 付费机场：注册后在用户中心获取
  2. 免费节点：访问 jd.222260.xyz 获取

注意：请复制"订阅链接"，不要直接填入网页地址。

其他问题

哪个客户端最好用？

各客户端特点：

  • Hiddify：最适合新手，界面简洁，一键连接
  • FlClash：现代化设计，功能强大，全平台统一
  • Clash Verge：经典稳定，功能丰富，适合进阶用户
  • v2rayN：老牌工具，协议支持最多，适合折腾

建议：新手首选 Hiddify，追求颜值选 FlClash。

如何更新客户端？

更新方法：

  1. 访问魔法云盘下载最新版本
  2. 直接安装覆盖旧版本（配置会保留）
  3. 或卸载旧版本后重新安装

提示：更新前建议导出备份配置。
